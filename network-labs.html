One topology, three skills.

Use a Cisco 1941 router, a Catalyst 2960 switch, and two PCs in a new Packet Tracer topology.

R1 · Cisco 1941
G0/0.10 and G0/0.20 gateways
VLAN segmentation
Separate the two PC access ports into VLAN 10 and VLAN 20. Carry both VLANs on the trunk to the router.
Inter-VLAN routing
Give each router subinterface a matching 802.1Q tag and a gateway address for its subnet.
DHCP addressing
Use one pool per subnet and reserve the gateway and first twenty addresses from automatic assignment.

Follow the lab in text.

The current networking resource is a written practice lab. No networking demonstration video has been supplied. Use this sequence alongside the configuration downloads.

  1. Build: connect R1 G0/0 to S1 F0/24, PC-A to F0/1, and PC-B to F0/2.
  2. Segment: create VLAN 10 for PC-A and VLAN 20 for PC-B. Make F0/24 a trunk carrying both.
  3. Route: configure R1 subinterfaces G0/0.10 and G0/0.20 with matching tags and gateway addresses.
  4. Address: add a DHCP pool for each subnet, exclude addresses .1–.20, and set both PC adapters to DHCP.
  5. Check: inspect VLANs, trunk state, interfaces, routes, and DHCP bindings; ping each PC’s own gateway before testing the other VLAN.
  6. Record: write down your observed results and save your own tested Packet Tracer file.

Verify before calling it complete.

Check access VLAN membership, trunk state, router interfaces, connected routes, and DHCP bindings. Then test each PC’s own gateway before testing the other VLAN.

The downloads include commands and expected behavior, rather than fabricated terminal output. Interface names and feature support depend on the selected device model.
